# Kalyan Jyoti Borah - Portfolio

Personal portfolio and freelance business site for Kalyan Jyoti Borah, a freelance software engineer and website developer based in Sivasagar, Assam, India, available for projects across Guwahati, Assam, and globally. The site showcases services, project case studies, and contact channels for custom website development and software engineering work.

## About

I am specialized in high-performance websites and scalable software for businesses, including:

- Custom website development (mobile-first, SEO-optimized, e-commerce and CMS solutions)
- Software engineering (scalable backend systems, API integrations, admin dashboards)
- Cloud deployment (AWS, Docker)

## Tech Stack

- [Astro](https://astro.build) (server output, deployed on Netlify)
- Tailwind CSS
- Markdoc for content collections
- GSAP for animations
- Embla Carousel
- Iconify

## Project Structure

- `src/pages` - site routes (home, about, works listing and detail pages)
- `src/components` - shared UI components (head/meta, socials, navigation, cards)
- `src/content/projects` - project case studies (Markdown/Markdoc)
- `src/data` - static data such as social links
- `src/layouts` - page layout shells

## Development

```bash
pnpm install
pnpm dev       # start dev server on port 3000
pnpm build     # production build
pnpm preview   # preview the production build
pnpm lint      # lint src
pnpm format    # format the codebase with prettier
```
